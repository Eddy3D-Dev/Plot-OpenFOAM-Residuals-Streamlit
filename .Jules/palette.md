## 2024-05-19 - Interactive Legends in Altair
**Learning:** Adding an interactive legend to Altair charts (using `alt.selection_point(fields=['Variable'], bind='legend')` and conditional opacity) is a highly effective, low-effort UX improvement for complex data visualizations like OpenFOAM residuals. It allows users to quickly isolate and focus on specific data series without cluttering the UI with additional form controls.
**Action:** When working with Streamlit + Altair line charts with multiple series, proactively add interactive legends. Additionally, ensure data manipulation (like `transform_fold`) uses dynamic column references instead of hardcoded lists to improve robustness for diverse user datasets.
